Dimensionamento Estrutural em Python

Projeto pessoal desenvolvido com o objetivo de aplicar conhecimentos de Engenharia Civil e programação na criação de uma aplicação para dimensionamento de elementos estruturais de concreto armado.

Sobre o projeto

A aplicação está sendo desenvolvida em Python e possui módulos voltados ao dimensionamento de:

Vigas: rotinas de cálculo para elementos estruturais.

Pilares: desenvolvimento de rotinas para dimensionamento de pilares de concreto armado.

Lajes: módulo destinado ao dimensionamento de lajes.

Tecnologias utilizadas

Python
PyQt5
Qt Designer
Matplotlib
Estrutura do projeto
Viga/ – arquivos relacionados ao módulo de vigas.
Pilar/ – arquivos relacionados ao módulo de pilares.
Laje(maciça)/ – arquivos relacionados ao módulo de lajes.

Status do desenvolvimento

Projeto pessoal em desenvolvimento. As funcionalidades estão em diferentes estágios de implementação e aprimoramento.
Observação: esta aplicação possui finalidade educacional e de estudo. Os resultados não devem ser utilizados diretamente em projetos profissionais sem verificação independente dos cálculos e validação técnica adequada.
